# Calagan Construction website

The website is built with the Next.js App Router. The source page and global styles are in `app/`; local images remain in `Images/` and are copied into `public/Images/` for Next.js to serve.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. To create and run a production build, use `npm run build` and `npm run start`.

The project uses React and Lucide React icons. Project enquiries open a prefilled WhatsApp message addressed to Calagan.
